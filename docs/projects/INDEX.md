## 案件追加時のチェックリスト

新規案件を始めるとき：

- [ ] `scripts/new-project.sh` で初期化
- [ ] 上記「アクティブ案件」テーブルに追加
- [ ] PROJECT_LEARNINGS.md にプロジェクト名・開始日を記入

案件完了時：

- [ ] PROJECT_LEARNINGS.md の最終内容を確認
- [ ] 残った還流候補があれば Issue 化
- [ ] 「完了案件」へ移動
- [ ] 主要な学びを `docs/learnings/` に整理

案件中止時：

- [ ] 中止理由を明記
- [ ] フレームワーク自体の問題が原因なら Issue 化
- [ ] 「中止案件」へ移動

## バージョン乖離トラッキング

最新版: v0.7.0（正本: `templates/project-init/.framework-version`）

| 案件名 | 案件のバージョン | 乖離 | 対応 |
|--------|----------------|------|------|
| - | - | - | - |

乖離が大きい案件への対応:
- 1 minor 以内: 問題なし
- 2 minor 以上: 取り込み検討 or 取り込まない理由を記録
- 1 major 以上: 案件単位で再評価
