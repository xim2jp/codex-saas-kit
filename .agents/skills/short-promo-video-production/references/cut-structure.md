# 30秒6カット構成 — 設計パターン

センセイメモ実績で確立した、SNS縦型30秒の**6カット構成テンプレート**。
カットごとに「役割」「手法」「尺」が決まっており、案件ごとに中身だけ差し替える。

## カット構成テンプレート

| # | 尺 | 役割 | 内容パターン | 手法 |
|---|----|------|------------|------|
| 1 | 0–4s | **フック（象徴カット）** | ターゲット人物が製品を使い、安堵/喜びの表情になる象徴的な1カット。メインコピー前半をテロップで特大表示 | **Sora 2**（image-to-video, 4秒） |
| 2 | 4–9s | **中核機能の実演** | 製品UIのモック（チャット画面・入力画面など）。実UIと乖離しない正確な再現が必須 | **Remotion**（UIモック） |
| 3 | 9–14s | **価値の蓄積・ビフォーアフター** | データが積み上がるモーショングラフィックス、カウントアップ演出 | **Remotion** |
| 4 | 14–18s | **感情ビート** | 同じ人物が成果を受け取り、肩の力が抜ける。**画面の中身は映さない**（ぼかし・後ろ姿）→ AI に UI 再現をさせないため | **Sora 2**（image-to-video, 4秒） |
| 5 | 18–24s | **差別化・信頼の訴求** | 最重要の差別化軸（セキュリティ・価格・独自機能）をUIモック＋アイコンバッジで明示 | **Remotion** |
| 6 | 24–30s | **ロゴ＋CTA** | ロゴ・タグライン・CTAボタン・URL。無料プラン等の具体的なオファーを明示 | **Remotion**（LogoCtaCut テンプレ流用） |

- **Sora 2 は2カット・計8秒（全体の約27%）に限定**する。これが「AI動画は差し色」の実証済みバランス
- カット1と4は**同一人物・同一参照画像**で生成し、ストーリー上の主役を一貫させる

## テロップ原稿のルール

1. **1文12〜20字目安**（スマホ縦画面での可読性の上限）
2. **抽象語禁止**（革新的・次世代・DX など）。数字で具体化する（「10秒以内」「38件」「月3件無料」）
3. 確定済みメインコピーがある場合は**一字一句変更禁止**（要件定義の Decision を確認）
4. 差別化軸（コンプライアンス・セキュリティ等）は専用カット（#5）で必ず1回明示する
5. 全カット分のテロップ原稿がそのまま .srt（クローズドキャプション）の正になる

### テロップ原稿の実例（センセイメモ）

```
1. 先生の観察を、通知表の言葉に。          ← メインコピー前半（フック）
2. LINEで、ひとことメモ。保存は10秒以内。   ← 機能＋数字
3. 積み重なる観察が、学期末の資産になる。    ← 蓄積の価値
4. AIが、所見の下書きを自動生成。          ← 感情ビートの説明
5. 児童の個人情報は、持たない設計。         ← 差別化軸
6. 学期中の10秒が、学期末の数十時間を消す。無料プランからはじめる。senseimemo.jp
```

## 冒頭3秒フックの設計

- 0–4秒で「ターゲットが自分ごと化できる象徴的な画」＋「メインコピー特大テロップ」を同時に出す
- 無音でも成立させる（フックをBGMや音声に依存させない）
- カメラはゆっくり寄り（slow dolly-in）が安定。派手な動きは Sora の破綻リスクを上げる

## 企画書（promo-video-plan.md）に必ず含める項目

1. 動画計画表（タイプ・目的・尺・比率・配信先・CV・主役・コピー）
2. カット表（上記6カットフォーマット。テロップ・音声/SE・手法列を含む）
3. 手法割り当てとコスト試算（試行3〜10倍を織り込む）
4. Sora 2 プロンプト草案（共通キャラクター記述ブロック＋カット別 Scene/Camera/Mood/Negative）
5. 一貫性破綻時のフォールバック（クイックカット化／手を映さない構図／全カットRemotion代替）
6. 制作・納品仕様（解像度・コーデック・字幕・配信先別仕様）
7. 権利・コンプラチェックリスト
