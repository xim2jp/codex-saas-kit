# RFP（提案依頼書）（docs/03-requirements/rfp.md）

> この文書について：クライアント案件の要件定義結果を、ベンダー選定・提案依頼に使える形にまとめる。本フレームワークの要件定義文書（requirements.md／business-requirements.md／use-cases.md／non-functional.md／permissions-matrix.md）を**発注者視点で再編**したもので、内容は同じ ID で結ぶ。空欄のまま埋めない。各セクションは要件定義の対話で確定した内容で埋める。
> 関連文書：要件定義書（requirements.md）／提案書（proposal.md）／決定ログ（decision-log.md）
